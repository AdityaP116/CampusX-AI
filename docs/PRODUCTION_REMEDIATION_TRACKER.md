# CampusX — Production Remediation Tracker

This document tracks all identified vulnerabilities, defects, architectural concerns, and remediation milestones as CampusX advances toward production readiness.

## Remediation Tracker Matrix

| ID | Issue | Severity | Affected File(s) | Root Cause | Proposed Solution | Status | Validation Result |
| :--- | :--- | :---: | :--- | :--- | :--- | :---: | :---: |
| **SEC-01** | Client-Controlled `campusx-authed` Cookie | **HIGH** | `frontend/src/middleware.ts`, `frontend/src/features/auth/services/authService.ts` | Cookie is set by JavaScript on client side as a plain flag (`1`), enabling anyone to manipulate browser cookies and pass Next.js route middleware. | Synchronize authentication state using server-side session handling or verified Firebase token validation; harden cookies with `HttpOnly`, `SameSite=Lax`, and `Secure`. | In Progress | Pending |
| **SEC-02** | Plaintext OTP Storage & In-Memory Single-Process State | **HIGH** | `backend/src/controllers/auth.controller.ts` | OTP is generated as a random integer and stored in plaintext in memory/Redis. In-memory fallback fails across clustered/multi-container deployments. | Hash OTP with SHA-256 before storing; enforce strict rate-limits, attempts, expiry, and single-use invalidation. | In Progress | Pending |
| **SEC-03** | Missing Production Email Delivery Provider | **HIGH** | `backend/src/controllers/auth.controller.ts` | In production mode, code currently logs "Sent verification code" without actual email dispatch via SMTP/Resend/Nodemailer. | Implement an email service supporting Resend / SMTP / SendGrid with graceful fallback and clear error reporting. | In Progress | Pending |
| **SEC-04** | Untyped Socket.IO and User Session Assertion | **MEDIUM** | `backend/src/server.ts` | `(socket as any).user` used for socket token attachment; lacks typed socket events, client interfaces, and conversation membership validation prior to joining rooms. | Define TypeScript interfaces for Socket data, client/server events, and verify conversation participant permissions before `join_conversation`. | In Progress | Pending |
| **DB-01** | Missing `firestore.indexes.json` Declaration | **MEDIUM** | Root repository, Firebase config | Compound queries on `products` collection (`status`, `category`, `createdAt`, `sellerId`) will fail at runtime in Firestore without composite index definitions. | Create `firestore.indexes.json` with all required composite indexes and update deployment instructions. | In Progress | Pending |
| **DB-02** | Client Fallback Over-reliance in `listingService.ts` | **MEDIUM** | `frontend/src/features/marketplace/services/listingService.ts` | Catches any error (including 401/403/400) and silently falls back to direct client Firestore SDK, masking backend authorization errors. | Refine fallback logic to only trigger on network/5xx server unavailability, not auth/client-side 4xx errors. | In Progress | Pending |
| **QUAL-01** | Excessive `any` and Non-Type-Safe Assertions | **MEDIUM** | `backend/src/models/*`, `backend/src/repositories/*`, `frontend/src/features/*` | Firestore data objects are cast as `as any` without complete DTO parsing. | Define strict TypeScript DTOs, document converters, and Zod schemas. | In Progress | Pending |
| **CI-01** | Missing GitHub Actions Automated CI Workflow | **MEDIUM** | `.github/workflows/ci.yml` | No automated CI pipeline exists to run linter, type-check, and automated tests on PR/push. | Create `.github/workflows/ci.yml` with dual-workspace (frontend + backend) type-checking, linting, testing, and building. | In Progress | Pending |
| **PERF-01** | Client-Only Rendering for Dynamic Product Routes | **LOW** | `frontend/src/app/product/[id]/page.tsx` | Product details route fetches entirely on client side, missing SEO advantages of Server Component rendering and dynamic metadata. | Implement Server Component data fetching or SSR/generateMetadata for public crawlers while preserving client interactions. | In Progress | Pending |
| **OPS-01** | Missing Production Envs & Redis Readiness Check | **LOW** | `backend/src/config/env.config.ts`, `backend/src/config/redis.config.ts` | Optional Redis URL silently degrades without clear observability in production clusters. | Validate Redis connection lifecycle and log appropriate warnings in production environments. | In Progress | Pending |
